# Telco Tech Namibia

Research platform for the Namibian telecommunications landscape — built with Astro, themed Gruvbox Tactical HUD, deployed to Hostinger via GitHub Actions.

**Maintainers (human or AI): read [`AI_MAINTENANCE.md`](AI_MAINTENANCE.md) before making changes.**

```bash
npm install
npm run dev      # local dev
npm run build    # must pass before pushing — push to main deploys live
```
